# Regulatory T cell

## Definition

Immunosuppressive CD4-positive T cell population that maintains self-tolerance.

## Markers

- FOXP3 is the lineage transcription factor used to identify the population.
- IL2RA (also written CD25) is high on the same cells, so a single marker is not
  enough to call a cell regulatory without activation context.

Related marker pages: [FOXP3](../marker_genes/FOXP3.md).
